# Windows Audio Switcher

ショートカットキーを押したままマウスホイールを回して、Windows の音声の出力先(モニター・イヤホン・スピーカーなど)をすばやく切り替える常駐アプリです。

## 使い方

1. `AudioSwitcher.exe` を起動します(インストールは不要。.NET を入れなくても動きます)。初めて起動すると、今つながっている出力デバイスが登録され、設定画面が開きます。
2. ショートカットキー(最初は **Ctrl + Alt**)を押したままにすると、画面右下(時計・通知領域の少し上)に出力先の一覧が出ます。
3. 押したままマウスホイールを回して、出力先を選びます(この間は実際の出力は変わりません)。
4. キーを離すと、選んだデバイスに切り替わり、一覧が消えます。ホイールを回さずに離したときは何も変わりません。

- 一覧の **左の色の帯・色のついた背景** が「選んでいるデバイス」、右の **「使用中」** が「今実際に使っている出力先」です。
- つながっていないデバイスはうすく表示され、選ぶときは飛ばします(登録は残るので、つなぎ直せばまた選べます)。
- ショートカットを押している間のホイールは、ほかのアプリには届きません(拡大・スクロールが起きません)。

## 設定(タスクトレイのアイコンをクリック)

| 項目 | できること |
|---|---|
| 操作 | ショートカットキーの変更(押して決める)、ホイールの向き、循環(最後 → 最初)のオン/オフ、切り替える用途(通話用も変えるか)、一時停止 |
| デバイスと順番 | Windows の出力デバイスから追加、登録から外す、表示名、使う/使わない、接続状態、上下の矢印で並べ替え(この順にホイールで進む)、今すぐ切り替え |
| 表示 | 選択UIの大きさ・位置(右下/左下/右上/左上/中央)・画面の端からのすきま・外観(Windows に合わせる/ダーク/ライト)・未接続を出すか・切り替えた結果の表示・Windows の通知 |
| アプリ | Windows の起動時に自動で起動、タスクトレイのアイコン、設定の保存、終了 |

タスクトレイのアイコンを右クリックすると、出力先を直接選んだり、一時停止・終了ができます。

- 設定の保存場所: `%APPDATA%\AudioSwitcher\settings.json`(変えるとすぐ自動で保存)
- うまく動かないときの記録: `%LOCALAPPDATA%\AudioSwitcher\log.txt`
- アンインストール: 設定の「アプリ」で自動起動をオフにしてから終了し、exe と上の2つのフォルダーを消す

## 動作環境

Windows 10 / 11(64ビット)。管理者の権限は要りません。

## 開発

- `src/AudioSwitcher.Core` … Windows に依存しない中身(切り替え順・ショートカットの判定・設定・表示位置)。`dotnet test tests/AudioSwitcher.Core.Tests` でテスト(Linux でも動く)
- `src/AudioSwitcher.App` … WPF のアプリ本体(Core Audio・キーボード/マウスのフック・選択UI・設定画面・タスクトレイ)
- GitHub Actions(Windows)でテスト・exe の作成・起動の確認・画面の画像(`--render-preview`)。タグ `v*` で Release
